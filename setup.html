Setup

From the download to your first launch. Four steps, no admin rights.

Getting it running

1 · Install it

Run the installer from the download page. It sets Revox up for your user account, so Windows does not ask for admin rights. Prefer no installation? The release also carries a portable archive — unpack it anywhere and run it from there.

2 · Pick your language

English and German. The installer asks once, and you can switch any time under Settings → Language without reinstalling.

3 · Build your library

Search for a game and add it to your library. Revox remembers where you left off, so the next launch takes one click. No Roblox sign-in happens here — it reads the public API only.

4 · Optional extras

Turn on playtime tracking to collect your own statistics, and Discord Rich Presence to show what you are playing. Both are off until you switch them on, and both can be switched off again.

Keeping it updated

New versions are verified against a built-in key before they install, so an update that does not come from this project is refused. You can also grab any build by hand from the releases page.
