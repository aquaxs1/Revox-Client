Features

Everything Revox can do

Four areas: playing, stats, friends and the little things that make it comfortable to leave running.

Playing

Start fast, pick up where you left off

Play screen

Your most recent game gets a big tile and a Play button, with your favourites in a row underneath and recent sessions down the side. Everything you need on one screen.

Rejoin any session

Every session Revox records keeps a Join again button. When it knows which server you were on, it takes you back to that exact one.

Your library

Add a game by name, Place ID or Roblox link. Type a name and Revox searches for you, then pulls in the icon, description and live player count.

Profiles

Keep favourites and playtime separate for each profile, each with its own chart. Handy when the PC is shared.

Stats

Know more than the website tells you

Explorer

Look up profiles, experiences and UGC items. On top of the usual numbers you get account age in days, followers per friend, like ratio, visits per active player, live server fill with median, and the resale markup on limited items.

Watchlist with history

Follow anything worth tracking. Revox takes a reading every six hours, so the detail view shows a trend line and what changed since last time.

Server browser

Joinable servers come first, sorted by ping and then by how busy they are. The best pick is marked and you can jump straight into any server on the list.

Playtime statistics

Total hours, how many different games you played and a 14-day chart, filterable per profile, with a most-played ranking.

Export

Take your sessions with you as CSV or JSON, saved wherever you choose.

Friends

See who is online and jump in

One-click setup

Revox spots which Roblox profile is yours and asks you to confirm it. If you would rather choose yourself, a search with avatars lets you pick a face instead of typing a name.

Live presence

Your friends list shows what everyone is doing right now, with joinable people sorted to the top.

Join in one click

When a friend's server is public, their Join button drops you straight into the same game.

Notifications

Get a desktop ping the moment a friend comes online or starts a game, so you can jump in while the server is still fresh.

Comfort

Set it up once and forget about it

Discord Rich Presence

One switch shows your friends what you are playing, with a live timer. Nothing to set up, it just works.

Tray and autostart

Revox can sit in the notification area and start with Windows, so your playtime keeps counting even with the window closed.

Setup wizard

Five quick steps on first run: welcome, language and theme, your default switches, the optional Roblox link, done. Every choice saves as you make it.

Themes

Dark, light or follow the system, six accent colours and three density modes. English and German, switchable without a restart.

Signed updates

New versions are verified against a built-in key before they install.

Under the hood

Built to last

Revox is developed in the open. The full source is on GitHub.

Stack

Tauri 2 with Rust, React 19 and TypeScript, on a hand-built design system.

Storage

A local SQLite database with versioned migrations, right on your PC.

Roblox data

Public Roblox APIs, called from Rust and validated before anything reaches the interface. Thumbnail sources are allow-listed.

Tested

104 frontend and 89 backend tests run on every change, including one that keeps both languages complete.
